# 素材筛选数据契约

## 目录白名单

| 目录 | 权限 | 用途 |
|---|---|---|
| `01_原始素材` | 只读 | 视频、音频、图片和相机附属文件 |
| `02_素材筛选结果` | 读写 | 给剪辑师查看和导出的结果 |
| `.xingchen` | 读写 | 配置、索引、缩略图、转写、日志和中间状态 |

导入素材时可以临时读取用户明确指定的来源路径。不得把该授权扩展到来源路径的父目录或其他磁盘。

## 项目状态

- `created`：目录已创建，未确认素材。
- `media-imported`：通过插件完成至少一次素材导入。
- `media-present`：发现手动放入的素材，但无法证明来源无遗漏。
- `validated`：素材通过筛选准入检查。
- `indexed`：完成文件和镜头索引。
- `screened`：已有 AI 候选结果。
- `reviewed`：剪辑师确认或调整过结果。

## 筛选记录字段

每条镜头或片段使用以下字段：

```json
{
  "id": "稳定唯一标识",
  "sourceRelativePath": "01_原始素材/相机A/A001.mp4",
  "startSeconds": 84.5,
  "endSeconds": 91.2,
  "startTimecode": "00:01:24.500",
  "endTimecode": "00:01:31.200",
  "thumbnailRelativePath": ".xingchen/thumbnails/...jpg",
  "transcript": "",
  "contentTags": ["老板", "包间", "讲话"],
  "technicalFlags": ["轻微抖动"],
  "selectionLevel": "重点候选",
  "recommendationReasons": ["出现重点人物", "提到开业优惠"],
  "confidence": 0.86,
  "reviewState": "未复核",
  "reviewNote": ""
}
```

## 推荐等级

- `重点候选`：直接满足 Brief 的必需人物、场景、动作、讲话或信息。
- `普通候选`：可用于环境、情绪、转场、节奏或补充叙事。
- `低相关`：与本次需求关联较弱，但不代表应删除。
- `待人工判断`：信息不足、身份不确定、置信度低或内容价值冲突。

## 技术风险

使用独立数组记录，例如：`无法解码`、`零字节`、`严重模糊`、`严重抖动`、`过曝`、`欠曝`、`黑屏`、`无音轨`、`疑似重复`、`异常短镜头`。技术风险不得自动改变内容推荐等级。

## 准入规则

`readyForScreening` 只有在以下条件全部满足时为 `true`：

1. 项目根目录、`.xingchen/project.json` 和两个必要目录存在。
2. 原始素材目录中至少有一个支持的视频、音频或图片。
3. 没有指向项目外部的目录链接。
4. 筛选结果目录可写。
5. 存在视频时，至少一条视频可被 FFprobe 识别；若 FFprobe 不可用，则阻断视频筛选并给出安装提示。

## 验收统计

首测至少记录：输入文件总数、成功索引数、失败数、总时长、AI 候选数、剪辑师最终保留数、AI 检查耗时、人工复核耗时和传统完整浏览估算耗时。
